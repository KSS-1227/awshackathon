1. REAL ENTITY EXTRACTION
   Not mocked counts. System produces non-zero entity/relationship numbers
   that increase when documents are processed.

2. ROBUST ERROR HANDLING
   Corrupt files don't crash the system. Errors are recorded and readable
   from the job status endpoint.

3. PROPER ASYNC CLEANUP
   Cleanup code is in finally blocks, so temp files are deleted on both
   success AND failure paths. This is a common area where bugs hide.

4. CUMULATIVE GRAPH STATE
   Re-uploading the same document doesn't duplicate entities. The builder
   correctly deduplicates and returns cumulative graph state.

5. PERSISTENT JOB TRACKING
   Jobs are persisted to disk, so status is recoverable even if the
   backend restarts between polls.
